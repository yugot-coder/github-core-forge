A standalone GitHub core forge in pure Python 3 (standard library only, no git binary at run time): git smart-HTTP with protocol v2 upload-pack and v0 receive-pack, REST v3, GraphQL and MCP surfaces over one deterministic in-memory store.

## Run it

```sh
MAKEFUN_ENV_URL=<suite env url> MAKEFUN_SHOP_TOKEN=<suite token> python3 main.py
```
